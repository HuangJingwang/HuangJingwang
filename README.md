### 🎙️ 最近在折腾什么

- **语音对话**：音频怎么进出 Pipecat，Agent 怎么听、怎么回答、怎么被打断。
- **看屏幕、调工具**：让 Agent 理解投屏，再通过 MCP 调用业务工具。
- **会议里的知识**：用 RAG 补充上下文，生成的任务和文档先交给人确认。
